MENU 10 V2
============

Bản V2 là web app/PWA an toàn: key + menu + aim trainer chạy trong chính app.
Không can thiệp, inject, sửa hoặc tự động điều khiển Free Fire.

KEYS

- VANNAM2026 (key mới)

CẬP NHẬT GITHUB/CLOUDFLARE
1. Mở repo GitHub menu10-app.
2. Thay index.html bằng index.html trong gói này.
3. Thay manifest.json và icon-180.png/icon-1024.png nếu muốn cập nhật avatar.
4. Commit changes vào main.
5. Cloudflare Pages liên kết GitHub sẽ tự build/deploy lại.

Nếu chỉ muốn cập nhật code, tối thiểu thay index.html.
